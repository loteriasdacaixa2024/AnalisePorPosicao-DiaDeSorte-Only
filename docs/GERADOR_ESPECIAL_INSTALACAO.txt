ENDPOINTS DA API:
==================

GET /gerador-especial/
   Renderiza página principal com último sorteio e estatísticas dos meses

POST /gerador-especial/api/gerar
   Input: {mes, quantidade, dezenas_por_jogo, valor_aposta, faixa, paridade, temperatura}
   Output: {sucesso, apostas[][], quantidade, valor_unitario, valor_total, mes, estrategias}
   Erro: 400 se mês não selecionado

POST /gerador-especial/api/exportar/txt
   Retorna arquivo .txt com formato: "02 05 08 11 14 17 20 MAR"

POST /gerador-especial/api/exportar/xlsx
   Retorna arquivo .xlsx com metadados + tabela de apostas

POST /gerador-especial/api/exportar/html
   Retorna arquivo .html com styling #D4B31A (ouro)

GET /gerador-especial/api/meses-stats
   Retorna meses mais atrasado e frequente

FILTROS E VALIDAÇÕES:
====================

FAIXA:
- Livre (default): Baixas + Médias + Altas
- Só Baixas: 01-10
- Só Médias: 11-20
- Só Altas: 21-31
- Baixas + Médias: 01-20
- Baixas + Altas: 01-10 e 21-31
- Médias + Altas: 11-31

PARIDADE (em 7 dezenas):
- Livre (default): Qualquer combinação
- Só Pares: todos pares
- Só Ímpares: todos ímpares
- 4x3: 4 pares + 3 ímpares
- 3x4: 3 pares + 4 ímpares

TEMPERATURA:
- Livre (default): Sem filtro
- Só Quentes: números com frequência alta
- Só Frias: números com frequência baixa

MÊS:
- Obrigatório (erro se não selecionado)
- Opções: Atrasado, Frequente, Janeiro-Dezembro, Aleatório

VARIÁVEIS RELEVANTES NO CÓDIGO:

templates/gerador_especial.html:

services/gerador_especial_service.py:

- generate_apostas(): Core logic com validações de filtro
- exportar_txt/xlsx/html(): Formatadores de saída
- classify_number(): Retorna faixa (baixas/medias/altas)
- is_hot_number(): Placeholder para números quentes

routes/gerador_especial_routes.py:
- gerador_especial_bp: Blueprint com prefix /gerador-especial
- 7 rotas HTTP implementadas
- Error handling com try/except
- JSON responses com 'sucesso' flag
