ENDPOINTS DA API
═══════════════════════════════════════════════════════════════════

GET  /gerador-especial/
     → Renderiza página principal

POST /gerador-especial/api/gerar
     → Gera apostas com filtros
     Input: mes, quantidade, dezenas_por_jogo, valor_aposta,
            faixa, paridade, temperatura
     Output: {sucesso, apostas, quantidade, valor_total, mes, estrategias}

POST /gerador-especial/api/exportar/txt
     → Retorna arquivo .txt
     Formato: "02 05 08 11 14 17 20 MAR"

POST /gerador-especial/api/exportar/xlsx
     → Retorna arquivo .xlsx
     Contém: Metadados + Tabela

POST /gerador-especial/api/exportar/html
     → Retorna arquivo .html
     Styling: #D4B31A gradiente

GET  /gerador-especial/api/meses-stats
     → {atrasado: N, frequente: N}
